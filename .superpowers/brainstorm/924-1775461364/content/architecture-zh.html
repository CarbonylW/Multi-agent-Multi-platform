🏗️ 技术栈选型

🐍 Python - LLM层

  • 大模型调用与推理
  • RAG知识库检索
  • Prompt Engineering

Go - 后端核心

  • Agent调度与通信
  • 传统规划算法
  • 冲突检测与消解
  • 仿真引擎

🎯 四大核心问题对应解决方案

  • 问题1：智能性 vs 实时性 → L1采用混合架构，大模型做态势理解，传统算法做规划调度
  • 问题2：三维空间冲突检测 → L1做全局仲裁，统一检测各设备航线冲突
  • 问题3：多Agent角色混淆 → 严格层级通信 + 指令签名权限校验
  • 问题4：鲁棒性与可扩展性 → 设备状态双上报，L1实时监控故障并重规划

📋 典型作战流程示例

  1. 态势感知：雷达/传感器发现可疑入侵者，获取大致方位
  2. 顶层决策：L1 Agent理解态势，从知识库检索预案，决定派遣多设备协同
  3. 任务分解：L1向无人机Agent、无人艇Agent分别下达作战规划
  4. 具体执行：各设备Agent规划具体航线，下发操控指令给设备
  5. 协同作业：无人机高空搜索、无人艇水面跟踪、潜航器水下警戒
  6. 状态反馈：设备实时上报状态给L1和L2
  7. 任务完成：成功驱赶入侵者，系统进入警戒状态
